# houseprice-prediction
A simple Machine Learning Project to predict house prices using Linear Regression and Boston Housing dataset

#Technologies Used
i.Python
ii.Pandas
iii.Scikit-learn
iv.Matplotlib
v.Seaborn
i.Google Colab

#Dataset
Boston Housing Dataset

#Steps
1.Load Dataset
2.Select first 100 houses
3.Split data into training and testing
4.Train Linear Regression Model
5.Predict house prices
6.Evaluate using MSE and r2 score
7.Visualize predicted vs actual prices

#Output
The model predicts house prices and visualizes actual vs predicted prices using a scatter plot.
